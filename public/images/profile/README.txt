Place your profile photo here and name it: jungudo-profile.jpg

The Hero component is configured to display this image when it is present.
Open /src/components/Hero.tsx and set `hasProfileImage = true` to activate it.

Recommended specifications:
- Format: JPG or WebP
- Dimensions: 800x1000px minimum (4:5 ratio)
- File size: Under 500KB (compress at https://squoosh.app)
- Style: Clean background, good lighting, professional appearance
